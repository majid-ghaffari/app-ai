# src/handlers/

**Parent:** [app-ai/CLAUDE.md](../../CLAUDE.md)

Route handlers. `src/index.ts` (the thin router) does CORS, the OPTIONS preflight,
and context-ID auth, then dispatches to one of these. Each handler owns one route
group and returns a `Response`; Anthropic access goes through `../lib/anthropic.ts`,
and the AI-tool surface comes from the toolset registry (`../toolsets/`).

## Files

| File          | Route(s)                                          | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `health.ts`   | `GET /health`                                     | Liveness check. No auth, no Anthropic call.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `files.ts`    | `POST /files`, `GET /files`, `DELETE /files/{id}` | Proxy to the Anthropic Files API. Upload routes through content-hash dedup (`lib/file-dedup.ts`) so identical bytes reuse a `file_id`; response shape stays `{ id, type }`. Success responses proxy as-is; failures return the Brain-shaped error envelope (missing file → 400 `ArgumentException`; Anthropic failures keep the upstream status as `AnthropicApiException` with the raw body in `MessageDetail`; 500 upload errors also get the beta-access hint in `Message`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `messages.ts` | `POST /messages`                                  | Single-shot Messages proxy — the **LIVE smart-image** surface. Injects the registry system prompt, uploads attachments (dedup), manages the 4-block `cache_control` limit, applies opt-in `effort`, best-effort `count_tokens` pre-flight, then proxies. Success bodies flow through unchanged; a non-ok Anthropic response returns the Brain-shaped envelope with Anthropic's status (`AnthropicApiException`, raw body in `MessageDetail`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `chat.ts`     | `POST /chat`                                      | Studio AI agent loop + SSE. Runs the Anthropic tool-use loop (`MAX_ITERATIONS=8`) against the tool surface composed per request from the toolset registry (`../toolsets/registry.ts`, endpoint allowlist `CHAT_TOOLSETS = ['personalizer']` — the `/v2/ai-tools/*` data queries + `get_entity_context`; see `../toolsets/CLAUDE.md`), streaming `text`/`tool_call`/`tool_result`/`done`/`error` events; non-streaming clients get the `done` payload as JSON. `fileIds` become `image`/`document` blocks (typed by Files-API mime), with a 1h cache breakpoint on the file prefix (placement screenshot + HTML). `context.refs` (entity references, cap 5 — `lib/references.ts`) are sanitized, eagerly prefetched, rendered as the UNCACHED final Referenced-Entities system block, and threaded into the agent loop for `get_entity_context`'s analytics dispatch; requests without refs send a system array identical to a refs-free build (cache safety). |

## Conventions

- Handlers receive `corsHeaders` from the router and spread them onto every `Response`.
- The context-ID is already validated by the router before any handler runs.
- AI tools are consumed ONLY through the toolset registry
  (`../toolsets/registry.ts`): each endpoint declares an explicit toolset
  allowlist and treats the composition as opaque — adding a toolset never
  edits handler logic. Standards: [docs/TOOLSETS.md](../../docs/TOOLSETS.md).
- Use `createLogger(scope)` from `../lib/logger.ts` for scoped, tail-greppable logs.
- Every HTTP error body — and every SSE `error` event payload — is the Brain wire
  shape (`{ Message, ExceptionType, MessageDetail? }`, built by `../lib/responses.ts`),
  so clients keep one error parser across app-ai and Brain. Handlers never invent
  per-route error envelopes ([docs/DECISIONS.md](../../docs/DECISIONS.md) #7).
- The live surface (`/files`, `/messages`) is in production — its routes, success
  request/response shapes, headers, and status codes are a stable external contract;
  keep them identical. Error bodies follow the Brain wire shape above.
